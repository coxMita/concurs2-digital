Format

  • Î: începe o întrebare; rândurile următoare continuă textul.
  • P: punctaj (opțional, implicit 1).
  • T: simplu sau multiplu (opțional; dedus din numărul de variante corecte).
  • + text variantă corectă, - text variantă greșită (2–8 variante).
  • Rândurile care încep cu # sunt ignorate. Un rând de text care începe cu \ este preluat ca atare.
  • Imaginile nu sunt incluse: adăugați-le după import, din editorul întrebării.
